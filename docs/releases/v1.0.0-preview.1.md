# ClipJob 1.0.0-preview.1

This is ClipJob's first public preview for Apple Silicon Macs.

## Highlights

- Summon ClipJob over the application you are using with a configurable global shortcut.
- Search reusable clips by label or content and paste with the keyboard.
- Create, edit, and delete clips stored locally in SQLite.
- Restore the previous application and clipboard text after pasting.
- Move and resize the palette, including across multiple displays.
- Show or quit ClipJob from its menu-bar icon.
- Check Accessibility and global-shortcut status from Settings.

## Before installing

This preview is free and **not signed or notarized with a paid Apple Developer certificate**. macOS will therefore warn that it cannot verify the developer. Follow the steps below to approve it manually. Only download ClipJob from this repository's GitHub Releases page.

## Install

1. Download `ClipJob-1.0.0-preview.1-macos-arm64.zip` below.
2. Double-click the ZIP, then drag `ClipJob.app` into **Applications**.
3. In Applications, Control-click ClipJob and choose **Open**.
4. Select **Open** in the warning. If Open is unavailable, try once normally, then go to **System Settings → Privacy & Security**, scroll down, and choose **Open Anyway** for ClipJob.
5. Open **System Settings → Privacy & Security → Accessibility**, find ClipJob, and turn it on. Use the **+** button to add `/Applications/ClipJob.app` if it is missing.
6. Quit and reopen ClipJob after granting permission.
7. Focus a text field in Chrome or another application and press **⌘⇧V**.

The download includes the .NET runtime; no developer tools or separate runtime are required.

## Requirements

- An Apple Silicon Mac (M1 or newer)
- macOS Accessibility permission for paste-back

Clip data stays on the Mac under `~/Library/Application Support/ClipJob`. ClipJob has no account, telemetry, cloud sync, or automatic clipboard history.
